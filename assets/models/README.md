# Model assets

Document units, axis conventions, scale, origin/pivot, LODs, collision intent, and material dependencies for every model.

The manifest recognizes glTF/GLB and OBJ model source extensions, but recognition is not model import support. Record metres, +X east/+Y up/+Z north, right-handed coordinates, UV convention, material dependencies, pivot, and collision intent. Model decoding/validation must be provided by an importer before these assets can be considered processed.
