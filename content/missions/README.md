# Missions

Mission manifests, ordered objectives, actor spawns, and campaign links. A mission may set `next_mission_id` to another manifest-registered `.tmission`; the reference must be listed as a dependency. Repeated `actor = actor-id -> faction-id -> x,z -> weapon-id -> reserve-rounds` records author infantry combatants. Actor faction IDs must be manifest dependencies and weapon IDs must exist in the Finnish 1939 combat catalog. Objectives may target either region placements or authored actors. Defeated actor targets are retained if combat occurs out of order, then consumed when campaign progression reaches them. Finnish support actors can assist once the player reaches the active engagement. The game runtime loads each successor into the same authored Sakkola region after the player completes the current mission and chooses to continue. The shipped Sakkola chain now moves from the First Patrol to the Northern Watch, the Defensive Line, and a non-combat aftermath mission. The aftermath records one localized roadside prop change through DynamicWorldSystem and returns the player to the church post. Omit the field to end the campaign chain. Reusable execution rules belong in src/talvisota/missions/.
